# Feedback — De Standaard

Reageer hier op de De Standaard-digest. Eén regel per item: het handle (bv.
`ds-0626-a3`), dan `+` of `-`, optioneel een notitie. De volgende digest leest
dit en scherpt de **Op maat**-selectie aan. De **Verrassing** blijft gevarieerd.

Voorbeeld (regels in dit codeblok worden genegeerd):

```
ds-0626-a1 + meer van dit soort duiding
ds-0626-v2 + verrassend goeie keuze
```
