# Feedback

Reageer hier op je gecombineerde digest (De Standaard + De Tijd). Eén regel per
item: het handle (bv. `ds-0626-a3` of `dt-0626-a1`), dan `+` of `-`, optioneel
een notitie. De volgende digest leest dit en scherpt de **Op maat**-selectie aan.
De **Verrassing** blijft bewust gevarieerd.

Het bron-voorvoegsel (`ds-` / `dt-`) zegt uit welke krant het item kwam.

Voorbeeld (regels in dit codeblok worden genegeerd):

```
ds-0626-a1 + meer van dit soort duiding
dt-0626-v2 + verrassend goeie keuze
```
