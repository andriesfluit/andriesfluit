# Feedback — De Tijd

Reageer hier op de De Tijd-digest. Eén regel per item: het handle (bv.
`dt-0626-a3`), dan `+` of `-`, optioneel een notitie. De volgende digest leest
dit en scherpt de **Op maat**-selectie aan. De **Verrassing** blijft gevarieerd.

Voorbeeld (regels in dit codeblok worden genegeerd):

```
dt-0626-a1 + meer van dit soort duiding
dt-0626-v2 + verrassend goeie keuze
```
